AirPods daemon isn't running

The app is only a front end: airpods-daemon talks to your AirPods. Start it (and enable it on login) with:

systemctl --user enable --now airpods-daemon.service

If it still won't start, run the built-in checks:

airpods-cli doctor

Your airpods-daemon is older than this app — some controls won't work until you update airpods-helper.
